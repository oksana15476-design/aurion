# AURION — Wordstat: что рынок ищет сейчас (спрос и рубрики)

> Данные: Yandex Wordstat (cloud API), регион **Россия (225)**, broad-match, показов/мес.
> Снято: 2026-07-08. Это относительные сигналы спроса, не точная частота.

---

## 0. Главный вывод (переворачивает приоритеты)

**Спрос сосредоточен на ПЛАТЕЖАХ, а не на регистрации компаний.**
Запросы про оплату/карты/платёжного агента (**суммарно >25 000/мес**) в разы больше, чем про
открытие компании за рубежом (**~1 000/мес** по всем странам). Люди ищут не «юрлицо», а
**способ платить за зарубежные сервисы и принимать деньги**.

**И ещё: модель AURION = «платёжный агент», и это ровно то, что рынок уже ищет.**
Запрос «платёжный агент» — **12 754/мес** (есть даже бренд-лидер «А7»). Это прямое попадание
в модель-агрегатор и главный SEO-якорь.

## 0a. ГИПОТЕЗА: «вывод бизнеса за рубеж БЕЗ своего юрлица» — оценка спроса

Гипотеза, которую тестируем: помочь компании работать в другой юрисдикции **без открытия
своего юрлица** (на обвязке-агрегаторе AURION).

**Прямой спрос под гипотезу — почти пусто:**
| Запрос | Спрос/мес |
|--------|-----------|
| вывод бизнеса за рубеж | 5 |
| вывести бизнес за границу | 4 |
| работать за границей без открытия компании | ~0 |
| выход на рынок Казахстана | 23 |
| выход на рынок ОАЭ | 10 |
| бизнес за рубежом под ключ | 4 |
| запуск бизнеса за рубежом | 4 |

**Смежное, но шумное/информационное (не покупатели):** продажи за рубеж 2 691 (мусор/экспорт),
диверсификация бизнеса 1 201 (академич.), выход на зарубежный рынок 301 (студенты/теория),
релокация компании 212 (в осн. соискатели), релокация бизнеса 71.

### Вердикт
**Это новая/латентная категория — прямого поискового спроса почти нет.** Люди не ищут
«вывод бизнеса за рубеж без юрлица», потому что не знают о такой возможности. Следствия:
- **SEO/органикой гипотезу дёшево НЕ проверить** — некого ловить.
- **Проверяем платным трафиком** (таргет/контекст) на смежную боль + лендинг как тест
  конверсии (совпадает с «pre-product, спрос инсайдерский → сайт+реклама = тест спроса»).
- **Точки входа латентной боли в поиске** (куда вести рекламой и редиректить на оффер):
  платёжная боль (приём выручки / оплата за рубеж) и релокация.

> Ниже (0b) — оценка смежного платёжного спроса. Это НЕ смена гипотезы, а карта точек входа,
> через которые латентную аудиторию «вывода за рубеж» можно достать платным трафиком.

## 0b. Смежный платёжный спрос (точки входа, не смена гипотезы)

Когда квалифицируем запросы по бизнесу/ВЭД (а не B2C), картина другая: **чистый
коммерческий B2B-спрос сидит в ВЭД-платежах (оплата поставщиков/инвойсов, расчёты с
Китаем, платёжный агент), а не в инфобизнесе.**

**✅ Чистый B2B-спрос, SEO-пригодный (наш клиент, высокий интент):**
| Запрос | Спрос/мес |
|--------|-----------|
| **оплата инвойса** (в китай 1 755, банки 1 921) | **9 459** |
| **вэд агент** | **1 126** |
| услуги платёжного агента | 610 |
| расчёты с китаем | 537 |
| платежи в юанях | 480 |
| платёжный агент китай (в китай 223) | 250 |
| платёжный агент вэд (для юрлиц 47) | 203 |
| платёжный агент для юридических лиц | 126 |
| оплата поставщикам в китай | 120 |
| расчёты с иностранными контрагентами | 111 |
| международные платежи для бизнеса | 83 |
| оплата контрактов вэд | 58 |

**⚠️ Шумный/B2C спрос (большой, но в осн. физлица — Netflix/ChatGPT):** «оплата зарубежных
сервисов» 11 377, «иностранная карта» 2 382, «оплатить подписку из россии» 2 268. Ловится
только широким соответствием + фильтрацией контентом лендинга; ядро — не наш клиент.

**⚪ Спрос ~0 (новая категория / только реклама+контент, не SEO):**
- Наш уникальный угол — «выход на рынок / продавать за рубеж **без своего юрлица**» — **~0**
  (никто не ищет, потому что не знает, что так можно → образовательный маркетинг, не SEO).
- Инфобизнес-формулировки — **~0** («эквайринг для онлайн школы» 4, «приём оплаты за курсы» 1).
- «оплата рекламы для юрлиц» / «платежи за рубеж для юрлиц» — **1** (боль есть, спроса в поиске нет).

**Вывод:** SEO-пригодный клин — **ВЭД-платежи / платёжный агент** (оплата инвойса, вэд агент,
расчёты с Китаем). Инфобизнес и «без юрлица» — реальны, но **невидимы в поиске** → на них
выходим рекламой/контентом/кейсами, а не органикой. Это влияет на выбор первого лендинга.

  - `карта для оплаты зарубежных сервисов` — 4 984
  - `виртуальная карта для оплаты зарубежных сервисов` — 3 578

Это язык модели AURION (агрегатор на своём юрлице = платёжный агент). Бренд А7 ранжируется —
значит, ниша живая и отвоёвываемая.

## 2. Что это значит для стратегии

1. **Клин ведём платежами, не регистрацией.** SEO/лендинг-хедтермы — из рубрик 1–2
   («оплата зарубежных сервисов», «платёжный агент», «иностранная карта», «как принимать
   оплату из-за рубежа»), а не «открыть компанию за рубежом».
2. **«Платёжный агент» — главный SEO-якорь** и это же и есть модель AURION. Отдельный
   лендинг/раздел под «платёжный агент» + перехват бренд-запроса «А7».
3. **Инфобизнес — это ТАРГЕТ и язык кейсов, а не поисковый хедтерм.** SEO ловит платёжный
   спрос; на инфобизнес выходим через рекламу/контент/кейсы (он ищет «карта для оплаты
   зарубежных сервисов», а не «эквайринг для школы»).
4. **Регистрация компаний = апселл/этап-2 слой**, с гео-приоритетом **Казахстан → ОАЭ →
   Армения** (по спросу).
5. **Не делать лендинг вокруг «дистрибьюторский договор» и «выход на зарубежный рынок»** —
   информационный/академический трафик, слабая конверсия.

## 4. Следующие шаги по семантике

- Снять **полную семантику по рубрикам 1–2** (`--limit 500–2000`, экспорт CSV) и
  кластеризовать (скилл `keyword-clustering`).
- Проверить **бренд-запросы конкурентов** (А7, Prodamus, Payoneer-аналоги) для перехвата.
- Снять **регионалку** (Москва/СПб/миллионники) и сезонность (`dynamics.sh`).
- По данным выбрать **финальные хедлайны** под каждый лендинг.

> Технически: скилл `yandex-wordstat` работает через Api-Key (env `YANDEX_API_KEY` +
> `YANDEX_FOLDER_ID`, маппятся в `YANDEX_WORDSTAT_API_KEY`/`YANDEX_WORDSTAT_FOLDER_ID`).
