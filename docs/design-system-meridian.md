# AURION · MERIDIAN — новая дизайн-система (предложение)

> Полная альтернатива текущей (тёплый пергамент + champagne-gold + Archivo/Hanken, editorial).
> Направление выбрано под продукт: кросс-бордер-инфраструктура, снижение риска, execution,
> лидген для предпринимателей (инфобизнес/e-com/IT/ВЭД). Дата: 2026-07-08.

## Концепция

**MERIDIAN** — «меридиан», линия пересечения границ. Холодный технологичный финтех-язык:
не «журнал», а **операторский пульт кросс-бордера**. Точность, данные, сигнал. Ощущение
инфраструктуры, которая переносит бизнес через границу быстро и без риска.

Антипод старой системы по всем осям: тёплое → холодное, золото → сигнальный лайм,
редакционные засечки настроения → гротеск + моно, воздух-журнал → плотная дата-сетка,
pill/скругления → острая техно-геометрия.

## Палитра — графит + сигнальный лайм (единственный акцент)

**Тёмная (основная):**
- bg `#0A0E13` (глубокий графит, холодный), панель `#111823`, приподнятая `#18212E`
- текст `#E9EEF3`, вторичный `#94A0AE`, muted `#5C6774`
- hairline `rgba(233,238,243,.08)` / `.14`
- **signal (акцент) `#C4F546`** — электрический лайм. Только CTA, хайлайты, live-точка, маркеры. На лайме текст — графит `#0A0E13`.

**Светлая:**
- bg `#EFF2F5` (холодная бумага), карта `#FBFCFD` (без чистого белого)
- текст `#0A0E13`, вторичный `#4C5763`, muted `#7A8593`
- hairline `rgba(10,14,19,.10)` / `.16`
- signal — тот же лайм `#C4F546` как заливка (текст на нём графит); акцент-текст на светлом — графит.

Дисциплина: **один акцент** (лайм) + нейтральная графитовая шкала. Без второго цвета,
без чистого `#FFF`/`#000`.

## Типографика — гротеск + моно (сигнатура системы)

- **Space Grotesk** (600/700) — заголовки, крупные цифры статистики. Техно-геометрия.
- **Inter** (400/500/600) — body, UI, подписи. Нейтральный финтех.
- **Space Mono** (400/700) — kicker/eyebrow, юниты цифр, теги, «координаты». Даёт технический характер (вместо editorial-eyebrow старой системы).
- Kicker — моно, UPPERCASE, часто с префиксом `//` или `→` (напр. `// MARKET_ENTRY`). Цифры — Space Grotesk, tabular.
- Wordmark **AURION** — Space Grotesk 700, трекинг .14em, сигнальная точка/маркер лаймом.

## Геометрия

- Радиусы малые/острые: карты 10px, инпуты/кнопки 8px, теги 6px (**не pill** — в отличие от старой системы).
- Крипкие hairline-границы. **Блупринт-сетка** тонкими линиями в фоне секций (технический слой).
- **Corner-ticks** (уголки-засечки) на ключевых картах — как кроп-марки чертежа.
- Плотная дата-сетка вместо журнального воздуха.

## Motion

- Резче и точнее: easing `cubic-bezier(.16,1,.3,1)`, 180–300ms.
- Сигнатуры: анимация счётчиков, hover = граница→лайм + микро-lift, live-точка мигает/пульсирует, лёгкий scan/grid-shimmer в герое, «печатающийся» kicker.
- Уважать `prefers-reduced-motion`.

## Компоненты

- **Kicker** (моно, `//` префикс, лайм-маркер).
- **Stat-блок**: моно-юнит + большая Space Grotesk цифра + подпись; corner-ticks.
- **Tag** — моно, бордер-хайрлайн, острый радиус; активный — лайм-заливка.
- **CTA** — лайм-заливка, графит-текст, стрелка `→`, снап-hover.
- **Card** — панель + hairline + corner-ticks + hover border→лайм.
- **Field** — тёмный/светлый инпут, focus = лайм-ринг.
- **Live-status** — мигающая лайм-точка + моно-текст (`● LIVE · 2026`).

## Голос

Тот же: уверенный, операторский, короткие утверждения, без хайпа («execution, not theory»).
Визуально — техничнее; микрокопия местами в моно-стиле (`NO_ENTITY`, координаты) — дозированно.

## Применение

- `landings/vyvod-za-rubezh/meridian-light.html` — нишевая, инфобизнес (светлая).
